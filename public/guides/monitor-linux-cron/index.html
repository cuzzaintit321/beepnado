How to monitor Linux cron jobs

Detect missed backups and scheduled tasks with heartbeat monitoring.

Why it matters

A successful cron exit does not guarantee that a task ran on schedule. A heartbeat monitor checks for a missing success signal.

How to set it up

Create a Heartbeat monitor, set the expected interval and grace period, and copy its private check-in command. Append that command after the actual job using && so failures do not send a success signal.

What to verify

For a nightly backup, allow enough grace time for normal completion. Test one successful run and one deliberately missed check-in in a test environment. Keep heartbeat URLs out of public logs.
