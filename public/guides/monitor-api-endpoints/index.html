How to monitor a JSON API endpoint

Check API status codes and application-level health.

Why it matters

An HTTP 200 response can still contain a degraded service state. Monitoring the JSON response helps distinguish transport success from application health.

How to set it up

Create a JSON API monitor for a public health endpoint. Set the expected status to 200 and, if your endpoint returns {"status":"ok"}, use JSON Pointer /status with expected value ok.

What to verify

Avoid embedding secrets or customer data in public health endpoints. Test a degraded response in staging before relying on alerts.
