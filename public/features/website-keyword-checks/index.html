BEEPNADO FEATURE GUIDE

Website and keyword checks

Monitor a public page for the response code, content, and speed you expect.

A page can return HTTP 200 while showing a maintenance notice or a placeholder. A keyword rule checks for a phrase that should appear in the page’s response. You can also set an expected status or response time limit.

How to use it

Add the exact public URL you want to watch. Open its monitor rules and enter the status, required text, or response time limit that tells you the page is healthy.

Pick a phrase that stays consistent across normal updates. Check that the phrase appears in the HTTP response your server sends.
