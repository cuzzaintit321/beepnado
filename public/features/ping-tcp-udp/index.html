BEEPNADO FEATURE GUIDE

Ping, TCP, and UDP monitoring

Choose a check that matches how your public host or service communicates.

An ICMP ping checks for an echo response. A TCP check tries to connect to a specific port. A UDP check sends a short request and expects a reply, with an optional matching prefix.

How to use it

Choose ICMP ping, TCP port, or UDP reply when adding a monitor. For a port check, enter the service’s public port. For UDP, supply the short request the service expects.

If a host answers ping and refuses TCP on port 443, investigate the listener, firewall, or proxy that serves HTTPS on that port.
