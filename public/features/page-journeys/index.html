BEEPNADO FEATURE GUIDE

Page journey monitoring

Check the pages customers depend on in order and see exactly which step stopped the journey.

A visitor can load your homepage while your pricing page is failing. A journey checks two to five public URLs on the same site as one monitor. Each step can require an HTTP status and a phrase in the response.

How to use it

In Monitors, choose Page journey. Enter your site’s public origin, then add each path and the response you expect.

In this example, BeepNado stops at Pricing. Open Investigate to see the status and timing of the steps it tried. Journeys make HTTP GET requests and check the responses.
