BEEPNADO FEATURE GUIDE

DNS, certificate, and domain monitoring

Check DNS answers and spot upcoming certificate or domain expiry.

A DNS monitor checks a record and can compare its answer with an expected value. A TLS monitor checks the hostname and certificate chain and flags an approaching expiry. A domain expiry monitor uses the registry’s RDAP data when an expiry date is available.

How to use it

Add the checks separately. Specify the hostname, DNS record type or expected answer, and the expiry thresholds you want to watch.

After a migration, confirm that the DNS answer points to the new host and that the new server presents a valid certificate for your domain.
