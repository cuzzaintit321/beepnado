Scheduled job heartbeat monitoring

Find out when a backup or scheduled job misses its expected check-in.

A heartbeat monitor waits for your job to send a private check-in after a successful run. If the expected interval and grace period elapse without a check-in, BeepNado opens an incident.

How to use it

Choose Heartbeat in Monitors and set the interval and grace period. Copy the private check-in command and have your scheduler run it only after the job succeeds.

For a backup that normally runs once a day, allow enough grace for occasional delays. The next valid check-in resolves an open heartbeat incident.
