BEEPNADO FEATURE GUIDE

Investigate a website outage

Review the exact check that failed and use the recorded evidence to decide what to inspect first.

Open a monitor’s investigation view to see its latest check and recent history. BeepNado groups recorded evidence such as DNS errors, TLS errors, timeouts, and HTTP failures. A page journey also shows the steps it attempted.

How to use it

Select Investigate on the monitor. Capture the URL, timestamp, and error. Then test the same URL from a separate network and compare the result.

An HTTP 502 is evidence that helps you narrow down the investigation. Check the proxy and upstream logs at the recorded time. Use the downtime checklist to work through the next steps.
