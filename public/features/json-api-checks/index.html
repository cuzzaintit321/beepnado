JSON API monitoring

Watch a public JSON endpoint and verify the value that tells you it is healthy.

BeepNado sends a GET request, checks the expected HTTP status, and parses the body as JSON. A JSON Pointer lets you check a specific value inside the response.

How to use it

Choose JSON API when you add a monitor. Enter the public endpoint, expected HTTP status, and optionally a JSON Pointer and expected value.

For a response such as {"status":"ok"}, the pointer /status selects the string ok. The example catches a degraded response even though the HTTP request succeeded.
