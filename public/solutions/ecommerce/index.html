Website monitoring for ecommerce stores

Watch public storefront pages and detect availability failures.

Why it matters

A storefront can appear available while a product or public category page returns an error. Monitor representative public pages independently.

How to set it up

Use a Page journey to check the homepage, a category and a public product page. Configure expected HTTP status and stable required text. Add certificate monitoring.

What to verify

These checks do not simulate a completed checkout, payment or authenticated cart. Use separate browser transaction testing for those workflows.
