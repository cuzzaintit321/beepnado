Why it matters

Different failure modes require different checks: an open TCP port does not prove an application is healthy.

How to set it up

Pair a website or JSON API check with a TCP check where useful. Add heartbeat monitors for scheduled work and DNS checks for important records.

What to verify

Use maintenance windows during planned changes and investigate recorded errors before assigning root cause.
