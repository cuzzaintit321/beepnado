WordPress uptime monitoring

Monitor public WordPress pages, TLS and DNS.

Why it matters

A WordPress homepage may be cached while a specific public page fails. Checking several meaningful endpoints can reveal failures hidden by caching.

How to set it up

Create a website monitor for the homepage and a Page journey for representative public pages. Add required text unique to each page and monitor SSL expiration separately.

What to verify

After a plugin or theme update, inspect monitor history and verify the affected pages. Do not expose wp-admin or credentials to public monitoring.
